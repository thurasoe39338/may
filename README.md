# Telegram Landing Page

A simple responsive landing page with a temporary cover image and one destination button.

## Edit the destination link
Open `index.html` and replace:
`href="https://example.com"`
with your real destination URL.

## Replace the temporary image
Replace `images/cover.svg` with your own image. If using a JPG or PNG, update the image path in `index.html`, for example:
`src="images/cover.jpg"`

## Publish with GitHub Pages
1. Create a GitHub repository and upload all files while preserving the `images` folder.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

The page is a normal landing page. It does not include deceptive ad-review cloaking or visitor-specific hidden content.
