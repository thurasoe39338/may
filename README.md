# MG HANGYI Gallery Landing Page

## Features
- Mobile responsive dark UI
- Horizontally swipeable tutorial cards
- HTML5 video player placeholder
- Telegram URL copy button

## Add your own tutorial images
Replace the sample SVGs inside `images/tutorials/`, or update the `src` and `data-image` paths in `index.html`.

## Add your own video
Place an MP4 file at `videos/tutorial-1.mp4`. Keep the filename, or update the `<source>` path in `index.html`. Video file is not included in this ZIP.

## Update Telegram link
The destination link is defined in `script.js`:
`https://t.me/channel_h1_bot/watch/`

## Publish with GitHub Pages
1. Upload all files and folders to your GitHub repository.
2. Go to Settings → Pages.
3. Choose Deploy from a branch, `main`, `/ (root)`, then Save.


## Step 1 PNG
The Step 1 tutorial image is included as `images/tutorials/step-1.png`. Its HTML references have been updated to use the PNG file.
